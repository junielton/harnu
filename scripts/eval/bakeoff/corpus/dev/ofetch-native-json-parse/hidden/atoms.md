| id   | requirement                                                                                                                                                                                                                                            |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| R-1  | The `destr` dependency is removed from the package.                                                                                                                                                                                                    |
| R-2  | Default response parsing uses the native JSON parser (`JSON.parse` or `Response.json()`) rather than `destr`.                                                                                                                                          |
| R-3  | When the response content type is JSON, the body is parsed strictly as JSON.                                                                                                                                                                           |
| O-1  | With a JSON content type (`application/json` or `application/*+json`, with or without parameters) and no override, a body that is not valid JSON rejects the call instead of falling back to raw text; the error class and message are not prescribed. |
| O-2  | Under a JSON content type, non-standard literals such as `TRUE`, `True`, `NULL`, `NaN`, `Infinity`, `-Infinity` and `undefined` are malformed and reject.                                                                                              |
| O-3  | Parsed values are what the native parser produces: `__proto__` and `constructor` keys are kept as ordinary own properties and `Object.prototype` is not modified.                                                                                      |
| O-4  | Numeric JSON bodies come back as numbers with native precision, even with more digits than a double holds, and never as strings.                                                                                                                       |
| O-5  | Non-JSON content types are unchanged: `text/*` returns text without a parsing attempt, `application/octet-stream` returns a `Blob`, `text/event-stream` returns a stream.                                                                              |
| O-6  | An explicit `responseType` still wins: `text`, `blob`, `arrayBuffer` and `stream` return that representation without parsing, and `json` parses a valid JSON body whatever the content type.                                                           |
| O-7  | `parseResponse` remains the override: called once with the raw text, its return value is the result, and a malformed body does not reject by itself.                                                                                                   |
| O-8  | A 4xx with a valid JSON body exposes the parsed value on `error.data` and `error.response._data`, `ignoreResponseError` returns it, and a 4xx with a malformed JSON-typed body still rejects.                                                          |
| O-9  | Status 204, 205 and 304 and `HEAD` requests are not parsed, even with JSON headers, and the result is `undefined`.                                                                                                                                     |
| O-10 | `$fetch.raw` exposes the parsed value on `_data`, and `onResponse` hooks see the same parsed value on `response._data`.                                                                                                                                |
| O-11 | `destr` is no longer declared as a runtime dependency in `package.json`, and no module under `src/` imports it.                                                                                                                                        |
