Context and decisions

Every gh call Harnu makes (mission PR and CI gates, PR Stack, Review, Cleanup merge checks, the steward) spends the operator's own GitHub budget: 5,000 REST calls and 5,000 GraphQL points per hour, shared with every session, script and monitor on the same token. On 2026-11-02 it ran dry, and Harnu showed nothing. It also kept checking PRs of missions that were already delivered.

Fixed across all four: the budget is read with gh api rate_limit every 60 s (that call is free); meters reuse the Plan usage anatomy and its 80/95 color ramp; Harnu counts only its own calls, so "Outside Harnu" is GitHub's total minus Harnu's share; below the threshold (15% by default) Harnu slows its own checks and stops checking delivered missions, and at zero it pauses them and shows the last known state until the reset.

Decision (2026-11-02): B, its own GitHub pill with attribution, plus D, the Settings pane with the throttle controls, reached from B's Details link. A (inside the usage pill) and C (silent until low) were explored and not chosen.

Sample data is fixed: 13:39 is when throttling began, 14:00 is the reset.
