# Blind builder-check: memory benchmark spec

AC-6 asks for a blind builder-check of S-2 (the live resume-eval) and the A/B protocol. A fresh subagent got only the spec (commit `d304acb0`) and was allowed to read only the files the spec names. It was told to list every decision it would have to guess to build S-2 and the A/B protocol. It wrote nothing and ran nothing.

**Result:** the first draft had 8 blockers and 9 minor findings. Every one is resolved in the spec now. Two claims were checked against the code before they were accepted (G-4, G-11). After the revision, no guess is left that the check found. The spec has not been re-checked blind; a second blind pass by the chapter 2 executor is the cheapest confirmation.

## A finding from building S-1 (not from the blind check)

The first run of the scorecard on this repo scored `recall_hit_at_5` = 1.0. Two causes made it meaningless:

- The gold page `decisions` is one 400 KB page that comes first in grep order.
- Each `query` had been copied from the heading of its gold section.

Both are fixed in the spec and the code:

- A gold id can be an entry or a `## ` section, and `recall_hit_at_5_strict` needs a match inside it.
- The validator refuses a `query` that is not a contiguous span of the question's own words.

The honest baseline is 0.7826.
