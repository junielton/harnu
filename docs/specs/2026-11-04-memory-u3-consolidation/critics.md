# Critic pass on the Memory U3 spec

Two sub-agents ran in parallel on the first full draft: a **blind builder-check** (given only `spec.md`,
asked whether it could build S-2 and S-3 and which guesses it had to make) and a **cost and safety critic**
(given the spec, the code, the real Scheduler run records in `~/.config/harnu/scheduler-runs/` and
`claude --help`). Every finding was fixed in the spec, turned into an open decision, or rejected with a reason.
A second pass of both critics then ran on the revised spec. The raw outputs are not committed.

## Blind builder-check, first pass

Verdict on the first draft: S-2 buildable with guesses, bordering on not buildable; S-3 not buildable.

## Cost and safety critic, first pass

The critic re-ran the measurements (they matched, apart from a median of 4 turns rather than 3 and p99
≈ 645,000 tokens, both corrected) and found that the first draft's worst case (≈ 5,340,000 tokens, $0.75 a day)
was too low, and that the gate as written could not bind at all.

| Raised                                                                                                                                                                                 | Outcome                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The daily gate counted only `ok` ticks; `runForOutcome` records 0 tokens for `timeout`, `stopped` and `error`, so the expensive ticks never count (≈ 91,000,000 tokens a day possible) | **Fixed.** The memory mode streams (`--output-format stream-json`); the shell sums usage live, records it on every run whatever the status, and counts it toward the day. Verified in `scheduler-shell.ts` before fixing.                                                                                                    |
| `--max-budget-usd` is checked between calls and dollars per token vary 35× (up to 89.8 million tokens per dollar), so one tick could reach ≈ 3,790,000 tokens                          | **Fixed.** The cap is in tokens: Harnu kills the tick at 400,000 streamed tokens. The dollar flag stays only as a backstop.                                                                                                                                                                                                  |
| A digest that always fails is retried forever                                                                                                                                          | **Fixed.** After two failed ticks it is logged `refused` (`TICK_FAILED`) and skipped.                                                                                                                                                                                                                                        |
| One digest per tick, idle hours only, can't drain ≈ 16 digests a day plus a 480-digest backfill                                                                                        | **Fixed in part.** A 2-minute drain gap while a backlog waits (the daily budget becomes the limit, ≈ 21 ticks a day), and the backfill is narrowed to signal-bearing digests (≈ 72; D-8). Recorded as a deviation from PRD §3.3's "hourly". The live load still fits only in idle time, so S-7 must report the real backlog. |
| Spend grows with the number of repos                                                                                                                                                   | **Fixed.** A global daily budget of 10,000,000 tokens across repos (D-4).                                                                                                                                                                                                                                                    |
| `startTick` spawns with `cwd: worker.folder` plus the companion `--plugin-dir`, so `--restricted` confines reads to the repo, not the tick directory; AC-11 checks argv only           | **Fixed.** The memory tick spawns in its own directory with no plugin or add-dir; AC-16 (fake binary records the cwd) and AC-17 (real CLI refuses a read outside it). Verified in `scheduler-shell.ts`.                                                                                                                      |
| Taint by citation is model-claimed: a hijacked model cites a clean span while copying tool text                                                                                        | **Fixed in part.** Taint now also fires on a 40-character verbatim overlap with any tool span. The stance says plainly that taint is a heuristic, and the boundaries no longer depend on it.                                                                                                                                 |
| An untainted `rule` auto-applies; `lintSecrets` has no instruction or URL check                                                                                                        | **Fixed.** A `rule` never auto-applies; a body with a URL, a command line or a tool-call shape parks.                                                                                                                                                                                                                        |
| An untainted proposal can auto-supersede an agent's entry and silently retire a real decision                                                                                          | **Fixed.** A supersede auto-applies only when the target was written by `worker` (D-7 widened to agent-written targets).                                                                                                                                                                                                     |
| The steward-style bearer is stable and `lintSecrets` doesn't know its shape                                                                                                            | **Fixed.** One bearer per tick, dead when the tick ends; `lintSecrets` refuses `mwt_` and `stw_` shapes (AC-14).                                                                                                                                                                                                             |
| `tickArgv` reads prompt, model and system prompt from `schedulers.json`, which an `act` session can edit                                                                               | **Fixed.** The memory mode builds prompt, model, effort, budget and tools in code; the record supplies only `folder` and `enabled` (AC-11).                                                                                                                                                                                  |
| A refused proposal whose body failed `lintSecrets` must not be logged                                                                                                                  | **Fixed.** A `refused` line holds the id and the code only (AC-22).                                                                                                                                                                                                                                                          |
| `WebSearch` is not on the deny list                                                                                                                                                    | **Fixed.** Denied by name (AC-11).                                                                                                                                                                                                                                                                                           |
| A shared central memory location would let one repo's worker read another's                                                                                                            | **Fixed.** The scope check compares the resolved memory directory, not the folder string (AC-12).                                                                                                                                                                                                                            |
| The CLI's reported cost is about one eighth of list price, so either dollars or tokens are off                                                                                         | **Not acted on, stated.** The spec sets every bound in tokens and says dollars are the CLI's own figure, which depends on the plan.                                                                                                                                                                                          |

## Second pass, on the revised spec

Both critics ran again on the revision.

**Blind builder-check.** S-2 was buildable with guesses and S-3 still was not, with two blockers.

| Raised                                                                                                                     | Outcome                                                                                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The tick context has no live targets, so `memory_propose` cannot compute `provisional` (blocker)                           | **Fixed.** The context carries `live: LiveTarget[]`, snapshotted by the shell; `provisional = applyDecision(p, matchSupersede(p, ctx.live))`; a duplicate is refused at propose time.           |
| How the tick reaches the MCP server and gets its bearer with no plugin dir; AC-11 lists no `--mcp-config` (blocker)        | **Fixed.** A per-tick config file written like `writeStewardMcpConfig` does, outside the tick directory, mode 0600, deleted at tick end; `--mcp-config` and `--strict-mcp-config` are in AC-11. |
| `bodyHash` undefined; a stored body ends with a provenance line, a proposal's does not                                     | **Fixed.** `bodyHash` is exported by the core (provenance stripped, whitespace collapsed, sha256) and every `LiveTarget` builder uses it.                                                       |
| `simulateSweep` needs a digest page and a date, and the core reads no clock                                                | **Fixed.** `StagedInput` carries `digestPage` and `date`; a new page's id and `valid_from` come from `staged.date`.                                                                             |
| The park reason is prose, but the lane and i18n need codes; "URL" and "shell prompt" undefined                             | **Fixed.** `ParkReason` codes and the three patterns are in the Apply decision table.                                                                                                           |
| How the digest splits into `d<n>`, which transcript entries become spans, and what happens when the digest alone overflows | **Fixed.** Split on `## ` headings; only non-noise chain participants, no `tool_use` input or thinking; the digest's last spans are cut last.                                                   |
| Proposal watches not normalized before comparing                                                                           | **Fixed.** `validateProposal` applies `normalizeWatch`.                                                                                                                                         |
| Bearer format, tickId minting, the `lintSecrets` regex                                                                     | **Fixed.** 16-hex tickId from a CSPRNG minted by the registry; HMAC-SHA256 hex; both regexes stated.                                                                                            |
| Do refused calls count toward the 8-call limit? How are refs numbered?                                                     | **Fixed.** Every call counts; `q<k>` numbers buffered proposals.                                                                                                                                |
| Is the scope check only on `memory_propose`?                                                                               | **Fixed.** On all three verbs.                                                                                                                                                                  |

**Cost and safety critic.** The first-pass fixes for rules, non-worker supersedes, `WebSearch`, the code-built
prompt, the per-tick bearer and the tick directory were confirmed. New or remaining:

| Raised                                                                                                                          | Outcome                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--output-format stream-json` in print mode needs `--verbose`; without it every tick dies at launch (blocker)                   | **Fixed.** `--verbose` is in the argv (AC-11); the S-4 reader parses the stream line by line, not the last-line `runFromResult` parse.                                                                                                           |
| A killed or failed tick's in-flight call is never streamed, so each one goes uncounted; worst case 5.1–6.2 million tokens a day | **Fixed.** A non-`ok` tick is charged `max(streamed, 500,000)`, and the gate reserves 500,000 at spawn. Worst case is now 4,000,000 tokens a day per repo.                                                                                       |
| "One call ≤ 100,000" does not hold: `memory_read` returns whole pages, and `decisions.md` is 406 KB                             | **Fixed.** Tick-bearer `memory_read` / `memory_query` results are cut to 16,000 characters (AC-12).                                                                                                                                              |
| Usage summing is unspecified (usage repeats per content block)                                                                  | **Fixed.** Once per `message.id`, four fields summed; an `ok` tick uses the final `result` usage.                                                                                                                                                |
| The global gate leaks when several repos tick at once                                                                           | **Fixed.** Both gates reserve at spawn.                                                                                                                                                                                                          |
| `$0.05` is below an expected tick (≈ 130,000 tokens at the highest rate), so legitimate digests would hit the two-failure skip  | **Fixed.** The backstop is `$0.25`, above the 500,000-token tick at the highest measured rate ($0.19).                                                                                                                                           |
| Which statuses count toward the two-failure skip                                                                                | **Fixed.** `error`, `timeout`, kill and budget stop count; `stopped` does not.                                                                                                                                                                   |
| A paraphrased directive in prose or a code block without `$ ` still auto-applies as a `gotcha` or `decision`                    | **Fixed in part.** A fenced code block now parks (`risky-body`). A directive in plain prose is not caught; the stance names taint and these patterns as heuristics, and the boundary is that pages reach a later session only fenced as context. |
| AC-17 tests only `Read`                                                                                                         | **Fixed.** `Grep` and `Glob` with an absolute outside path too.                                                                                                                                                                                  |

**Residual guesses.** Every second-pass finding above was fixed in the spec or stated as a heuristic; no third
pass was run, so these fixes are the author's and have not been re-checked by a critic. What stays open is
the operator's (D-1 to D-9) or another unit's (D-10 for U4, D-11 for the benchmark), and is recorded as such.

**Worst case on this repo at the default cadence: 4,000,000 tokens a day** (≈ $1.53 at the highest rate the CLI
reported; ≈ 3,000,000 tokens and ≈ $0.10 expected). Across all repos: 10,000,000 tokens a day.
