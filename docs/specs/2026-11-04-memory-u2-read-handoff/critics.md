# Critic pass on the memory U2 spec

One sonnet sub-agent ran a **blind builder-check** on the first full draft (five slices, 30 ACs,
seven open decisions). It was given only `spec.md`, with no code and no other document, and asked
whether it could build S-2 (the typed handoff derivation) and S-3 (boot injection) alone, which
guesses it had to make, and where the spec contradicted itself. This file records what was raised
and what changed. The raw output is not committed. The revised spec was not re-checked by a
second blind pass; the fixes below were checked against the code by the author.

## Blind builder-check

Verdict on the draft: S-2 buildable with guesses, S-3 buildable with guesses.
