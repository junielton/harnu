Point and comment

The header's message-square-plus button (or Ctrl+Shift+C with the pane focused) turns on picking. Hover outlines the node with its tag and size, and a click pins it. Sent pins fade; draft pins stay solid.

What the session receives

On the left, the turn arrives as [harnu-comment]. Your text is the request; selector, HTML, styles and URL are labelled as page-authored. The crop goes by path, never as bytes.

Docked vs floating (OQ-2)

Toggle "Composer" above. Docked lives in the app chrome: the page cannot read keystrokes, and there is no overlay-under-native-view problem. Floating sits at the node, but a hostile page can keylog it.

Live panel = a file

An agent or mod writes .harnu/out/panels/t564.html once, then only sends setData. The page renders its own state. The highlighted row is the last update.

Three writers, one door

The session, the harnu-progress mod and an observe worker all write through the same browser_* verbs. The footer strip shows who wrote it. The offline badge means the page has no network (OQ-3).

Page talks back

"Approve U3" calls harnu.emit. It only counts after a real click (gesture gate), and it arrives as [harnu-page-event], data rather than an order.

Real emulation, not a narrow window

CDP sets the width, height, DPR, mobile flag, touch and UA. Media queries and <meta viewport> behave as on a phone. The frame is scaled to fit the pane, and the page never sees that scale.

Header controls

Preset picker (classes: phone-s/m/l, tablet, laptop, desktop), free size, rotate, light/dark and reduced motion. Zoom is disabled in device mode (OQ-15).

Network capture

The red Network 4:12 counter shows recording that the agent turned on. It stops by itself and records no bodies unless they are asked for.

Pause and Disconnect

Pause blocks agent writes for 10 min with a countdown and Resume, and reads keep working. Disconnect is permanent: the chip turns red and the pane stays yours.

Frozen frame

When a menu or dialog from the app overlaps the native view, the pane shows a still image (capturePage) until it closes. Without this, the menu would draw under the page.

External and discarded

A domain opened by an agent gets the amber "opened by agent" badge. A pane hidden for 10 min is discarded to free 100–300 MB and reloads with one click, or on its own when a verb needs it.
