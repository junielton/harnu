## 0. Summary and the decisions that need a human

Harnu has **26 modal-like surfaces** (24 own components + 2 inline overlays) and **no shared shell**. Each re-implements Teleport, scrim, card, header, footer, Esc, backdrop-close and (mostly) focus handling, and they have drifted: 5 `max-height` values + 2 dialogs with none + 2 fixed heights, 9 widths, 3 radii, 2 scrim values (3 counting the viewer), 4 z-index values among dialogs, 3 close-state idioms, and no dirty-guard convention beyond two components. BUG-184 is just the first drift that hurt.

**Recommendation.** Build one `components/ui/Dialog.vue` (+ `useDialogStack`), tokenize the scrim / cap / z-layers, and migrate in **9 PRs behind a characterization-test net that lands first**. Land **BUG-184 first as a standalone fix, written in the primitive's final shape** (§7). The migration is a _shell swap_: component names, emits, store contracts and every `data-testid` / `data-test` / `data-dsqa` stay exactly where they are.

## 1. Inventory (AC-1)

### 1.0 Scope rule

"Modal-like" = blocks the app behind it with a scrim **or** is a `role="dialog"` overlay. Anchored popovers/menus/previews, takeovers, toasts and non-blocking drag overlays are **out of scope** and listed in §1.3 with the evidence for each, so the boundary is auditable.

Search used: every `*Dialog.vue` / `*Modal.vue`, `McpConfirmOverlay`, plus `git grep -lE 'Teleport|fixed inset-0|position: fixed' src/renderer/src` (50 files) — each file classified.

**Close-state idioms (4):** (a) `ui.closeDialog()` for the 11 `DialogId` dialogs (`stores/ui.ts:12-24`, a one-at-a-time mutex); (b) `emit('close'|'cancel'|'confirm')` to a parent-owned `v-if` flag, with three different payload shapes (`[]`, `[success: boolean]`, `[tombstone: string|null]`); (c) a local ref + local keydown (HarnuModExternal, MissionsReview, the two inline overlays); (d) McpConfirmOverlay's IPC verdict. The primitive must serve all four without forcing a rewrite of any (§5).

**Hooks other than `data-testid`:** `data-test` on the three Mission dialogs, `data-dsqa` variants on ContainersRemove. Only 4 dialogs carry `data-testid` (CleanupBulk 21, HarnuModExternal 7, ContainersRemove 2, Dehydrate 1). The other 17 expose no test hook.

**Stacking today (modal-over-modal / modal-over-popover):** HarnuModExternal over Settings; MissionBulkClose over MissionsReview (parent's trap is switched off while `confirming`); MissionClose over the Topbar mission popover; BranchCombobox/FolderCombobox panels (z-70) over any dialog. Each handles this by hand. A single Esc currently reaches every mounted window-capture listener, because `stopPropagation()` does not stop other listeners on the same target — the per-dialog `confirming` guards exist precisely to compensate.

## 2. What we measured about the tooling the migration depends on

- **Test stack:** Vitest 2 + `@vue/test-utils` 2 + jsdom (opt-in per file with `// @vitest-environment jsdom`); `tests/**/*.test.ts`. jsdom has **no layout engine** — `getBoundingClientRect()` is all zeros — so "the footer is on screen" can only be proven in a real browser (§6.3).
- **Playwright:** `playwright-core` + `@playwright/test` are dependencies; `npm run e2e` runs `tests/e2e/*.spec.ts` against a **running** app over CDP (`:9222`). Only one spec (`folder-sort`) opens a dialog today.
- **Contract-test precedent:** `tests/cleanup-design-contract.test.ts` reads component source and asserts design-token rules (no raw sizes outside a documented allow-list). The same pattern gives us a cheap ratchet for "no hand-rolled shell" (§6.4).
- **App shell:** `html, body, #app { overflow: hidden }` (`main.css:28-35`). Nothing behind a dialog can scroll the page, so a scroll-lock is **not required**; the contract suite asserts the shell invariant instead of implementing a lock (§6.1).
- **i18n:** the close button's `aria-label` is a per-dialog key (`renameFolder.close`, …) — there is no shared `dialog.close`. The primitive needs one, in **both** `en.json` and `pt-BR.json` (`MessageSchema = typeof en`, so a missing key breaks `vue-tsc`).
