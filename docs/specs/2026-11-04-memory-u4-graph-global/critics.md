# Critic pass on the memory U4 spec (graph and global layer)

One sonnet sub-agent ran a **blind builder-check** on the first full draft (six slices, 41 ACs, 12 open
decisions). It was given only `spec.md`, allowed to open the code the spec cites, and asked whether it could
build S-1 (link index) and S-4 (global layer) and which guesses it would have to make. This file records what
was raised and what changed. The raw output is not committed.

## Blind builder-check

Verdict on the first draft: **S-1 buildable with guesses, S-4 not buildable as written.** After the fixes
below, no guess is left open: each is fixed in the spec, or is a precondition, a D-n or a non-goal.
