# T389 spec review A: foundation, P1 and P2

**Reviewer:** independent (did not write the documents) · **Date:** 2026-10-02 ·
**Epic:** T389 (Harnu mod) · **Companion review:** P3 to P5 (another reviewer, concurrent).

Finding ids are written `RA_n` with an underscore on purpose. A hyphenated id with two or more
digits has the shape of a tracker key and fails `tests/no-client-identifiers.test.ts`
(DOC-9, ADR-0018 C15) as soon as this file is tracked.

## 1. Scope

Read in full: `docs/specs/T389-companion-mod/00-master.md`, `01-contract.md`,
`docs/adr/0018-harnu-mod-as-integration-substrate.md`, `docs/studies/T389-smoke-evidence.md`
and the eleven wave specs `P1W1` to `P1W6` and `P2W1` to `P2W5`. Not reviewed, not edited: `P3*`,
`P4*`, `P5*`.

## 2. Method

1. Index first: master §4, §5, §7, §12, §13, the contract's constants (§7), events (§8), commands
   (§9), features (§11), `$.state` registry (§22), then each wave's Depends-on, Design,
   Arbitration and fallback, ACs and "Contract additions".
2. Cross-checks, by script or grep, over all eleven specs:
   - every AC has one of the six allowed methods, an `Evidence:` line, contiguous numbering and no
     duplicates (339 ACs before the fixes below added eight);
   - every cited requirement id exists (SEC, ARB, MOD, QA, DOC, OD, R, Q, CQ, C, D, F, conformance
     rows); every cited BUG id exists in the repo; every cited smoke id has a section in the
     evidence document (three exceptions, `RA_18`);
   - names of events, commands, features, constants, interfaces and state keys against the
     contract and master §12.1 (owner defines, consumers conform);
   - smoke refutations and untested behaviours (single fetch over 30 s, `prompt.compose` mid-session,
     `$.ui.notice`, `PostToolUseFailure`, a Bash `tool.call` hook): none is relied on; the
     untested ones that are used carry an open question and an AC (exceptions in the table);
   - the two identifier gates of the repo test (`[A-Z]{2,6}-[0-9]{2,6}`, lowercase form,
     the workspace-directory forms) plus home paths and session uuids: clean (only `ADR`, `BUG`, `TASK`,
     `argv`, `bug`, `non` prefixes match, all allowlisted);
   - English only outside the i18n table of P1W4 (the allowed exception);
   - user-visible strings: none says "companion" except the engine-drawn plugin-name prefix that
     the specs already flag (master §15); the slash command is `/harnu-link` everywhere.
3. Severity. BLOCKING: an engineer would build something incompatible, wrong or unverifiable.
   MINOR: wording, convention, a weak AC, an omission an engineer would fill from the contract.
4. BLOCKING findings were fixed in place with minimal edits; prettier was run on every edited file.
   Nothing was staged or committed.
