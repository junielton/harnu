Docker address pools Add more room for Docker networks

Docker is using its default address pools, which hold 31 networks. Free slots fell to 3 on this machine. A wider pool gives every compose project room to start.

  1. Add this to /etc/docker/daemon.json
    If the file already exists, add the key to it instead of replacing the file. Pick a range your VPN and LAN don't use. 
    {
  "default-address-pools": [
    { "base": "10.200.0.0/16", "size": 24 }
  ]
}
    256 networks of /24, from 10.200.0.0/16.
  2. Restart the Docker daemon
    For example sudo systemctl restart docker. Containers without live-restore stop while it restarts.
