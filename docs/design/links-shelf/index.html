Contexto e decisões

Problema: imagens coladas têm a galeria do footer; links (task, PR, Figma, docs) somem no meio de uma sessão longa e não têm onde serem consultados nem re-referenciados.

Decisões: sem hook — Harnu já lê o transcript .jsonl, então extrai as URLs dele (inclusive histórico). Um pill 🔗 N ao lado do 🖼 N, mesma gramática (hide-when-zero, aberto = accent). A linha mostra um rótulo tirado só da URL, sem rede (PR → owner/repo #n, ClickUp → Task <id>, Figma → nome do arquivo + nó, resto → host+caminho em mono). Título de página fica pra v2. O trecho da mensagem só aparece no hover, como contexto. Origem marcada: you (colado por ti) ou agent (produzido pelo agente, ex. PR que ele abriu).

Ações: Abrir · Copiar · Referenciar (insere a URL no composer, sem Enter — igual ao Re-attach das imagens; desabilitado sem PTY viva).

Em aberto: o escopo "Folder" (todas as sessões da pasta) ainda não foi confirmado como necessário — pode cair.
