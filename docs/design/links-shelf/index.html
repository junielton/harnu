Context and decisions

Problem: pasted images have the footer gallery; links (task, PR, Figma, docs) get lost in the middle of a long session and have nowhere to be looked up or referenced again.

Decisions: no hook — Harnu already reads the .jsonl transcript, so it extracts the URLs from it (history included). A 🔗 N pill next to the 🖼 N one, same grammar (hide-when-zero, open = accent). Each row shows a label taken from the URL only, with no network (PR → owner/repo #n, ClickUp → Task <id>, Figma → file name + node, anything else → host + path in mono). Page titles are left for v2. The excerpt of the message only shows on hover, as context. The source is marked: you (pasted by you) or agent (produced by the agent, e.g. a PR it opened).

Actions: Open · Copy · Reference (inserts the URL into the composer, without Enter — same as the images' Re-attach; disabled without a live PTY).

Open: the "Folder" scope (every session in the folder) has not been confirmed as necessary yet — it may be dropped.
