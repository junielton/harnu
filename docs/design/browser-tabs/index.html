Context and decisions

Today: one browser pane = one page. A link that opens a new window becomes a new pane in the split. A pane opened with no address is empty, and a load that fails (for example localhost:8000 with nothing listening) stays a blank white view. The address field shows two borders on focus: its own plus the global focus ring.

Tabs. With one tab the pane looks exactly like today, plus a + in the header. From the second tab on, the strip takes the title's place in the same 24px header; no new row. The active tab opens into the address bar (same --bg) (no accent line). Ctrl+T new tab, Ctrl+W close, Ctrl+Tab next. A page's target=_blank link opens as a tab next to its opener instead of a new pane.

Logins. Every tab of a pane uses the pane's cookie partition: your panes share your logins, an agent pane's tabs stay isolated. No new rule.

Narrow panes. Inactive tabs collapse to their icon, the active one keeps its title, the rest go behind a +N list.

Agents. The "Connected to…" chip becomes one pulsing icon in the header; hover shows who is connected and what it is doing. Paused and Disconnected keep their text pill (they must be seen). Disconnect stays next to it; the tab the agent is driving shows the live dot instead of its icon. Verbs would take an optional tabId (defaults to the active tab).

Start page. Only what is useful: servers running in this folder (from Docker stacks and terminals Harnu already sees) and recent sites of this folder's panes. Nothing else.

Load error. Harnu draws its own page: what failed, a hint for local hosts, the error code, Reload, and "Reload when it is up" (polls until the port answers, then loads).

Focus border. The address field keeps one border (--accent-line) and opts out of the global focus ring, as the Ask box did in c6930c3c. This one is a small fix that can ship alone.

Flows

Open a second tab and type an address — percorrer ↗

  1. browser-pane?state=single via "+ in the header"
  2. browser-pane?state=new-tab via "type an address, Enter"
  3. browser-pane?state=tabs

Close the other tabs from a tab's menu — percorrer ↗

  1. browser-pane?state=tabs via "right-click the Dashboard tab"
  2. browser-pane?state=tab-menu via "Close other tabs"
  3. browser-pane?state=single

Open the browser with no address and pick a running server — percorrer ↗

  1. browser-pane?state=start via "click example-web"
  2. browser-pane?state=single

Reach a tab that does not fit — percorrer ↗

  1. browser-pane?state=overflow via "+4"
  2. browser-pane?state=overflow-list via "pick a tab"
  3. browser-pane?state=overflow
