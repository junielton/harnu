Context and decisions

Everything about a mission goes back into a dropdown that opens from the Mission pill in the Topbar. The Mission pane in the helper stack goes away. The dropdown is built from the v4 model and the v4 pane’s pieces, under one rule: every element must earn its place; anything the operator owes is never hidden.

Folded in from the operator’s feedback: sessions removed from the user’s view (the data and the backend stay); worktree links as branch names, one “Evidence” link, no absolute paths, copy available (BUG-288); a hover label on every state dot (BUG-285); proper spacing for Ask (BUG-287); the next-step button on the right of the text when wide and under it when narrow, in the compact size; no “Ready to close” badge; only the current milestone open.

Use the Dark / Light switch at the bottom right of the frame, or open a screen alone with ?theme=light. Widths: 1280 is a wide window, 360 a narrow one. The table of what changed against the current pane is in Spec.

mid Mid-way. One next step (button on the right when wide, under the text when narrow), only the current milestone open, the rest folded.
closed The pill at rest. A caret says it opens.
multi A session that leads several missions: one switch line above the title.
chooser The switch open: pick the mission to show.
owed “2 more waiting on you” opened in place. Everything owed stays one click from the top.
step-open A step opened inline: criteria (verified ones folded), the PR link, a branch link with copy, one “Evidence” link.
blocked A blocked step: the blocker, “Done, continue”, criteria and links.
ask Ask on the current milestone. The Ask button sits on the summary line with its own gap.
done-when A staged Done when replaces the next-step box: Approve / Decline, no “Review it” hop.
attach-request A session asks to join: Allow / Deny in the same slot.
ready Ready to close: no “Ready to close” badge; the next step says it and the pill turns green.
close-confirm The close dialog.
empty No mission: a muted icon-only pill; the picker with Attach and Start a new mission.
dots Hover labels, forced open on a milestone dot and a step dot. Every dot has one on hover and on focus.

  1. closed via the Topbar pill
  2. mid via the step “Score the proofs each criterion names”

  1. mid via “2 more waiting on you”
  2. owed via “Open step” on the blocked item
  3. blocked via “Done, continue” on the blocker
  4. mid

  1. mid via Ask
  2. ask via Send
  3. mid

Answer a staged Done when — walk it ↗

  1. done-when via Approve
  2. mid

Let another session join — walk it ↗

  1. attach-request via Allow
  2. mid

Close a finished mission — walk it ↗

  1. ready via “Close mission…”
  2. close-confirm via Close mission

  4. mid

  3. multi
